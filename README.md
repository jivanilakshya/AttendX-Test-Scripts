# AttendX-Test-Scripts

## Project Description
This repository contains demonstration test scripts
for the AttendX student attendance application.

## Test Scripts

### 1. test_login.py
Tests valid credential inputs and empty username validation.

### 2. test_attendance.py
Tests attendance status validation for Present, Absent,
and an invalid status.

## Technology Used
- Python
- Git
- GitHub
- Visual Studio Code

## Purpose
To demonstrate version control of QA test scripts
using Git and GitHub.

## Version Control
This project uses Git and GitHub to track changes,
maintain commit history, and share test scripts.
